§3Palette sweep — every installed theme

The whole point of this section: if state reads correctly in all of these, hue is no longer load-bearing. collapse marks a theme where accent === foreground, so starting and running are the same colour and only the spinning glyph separates them. light marks a light-foreground theme, where Qt.darker() moves the wrong way — see §4.

§4De-emphasis: Qt.darker vs Util.alpha

Panel.qml currently dims secondary text with Qt.darker(fg, 1.4), copied from the native panels. On a dark theme that reduces contrast against the background, which is the intent. On a light theme the foreground is already dark, so darkening increases contrast — the "dimmed" text ends up more prominent than the primary label. Util.alpha(fg, 0.7) blends toward the background instead, so it de-emphasises in both directions. Contrast ratios are computed against each theme's own background.
